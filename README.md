# 🎮 Rock Paper Scissors Game

A simple, interactive **Rock Paper Scissors** game built using **HTML, CSS, and JavaScript**. Play against the computer, track your score, and enjoy a smooth, responsive UI!

## 🧠 Features

- Classic rock-paper-scissors logic
- Responsive UI for desktop and mobile
- Score tracking system
- Play again/reset functionality
- Fun and lightweight browser game

## 📦 How to Run Locally

Follow these steps to run the game on your machine:
```bash
# 1. Clone the repo
git clone https://github.com/manishh-18/Rock-Paper-Scissors.git

# 2. Navigate into the project folder
cd Rock-Paper-Scissors

# 3. Open index.html in your browser
```
✅ No additional installations or dependencies are required.
